# ЧТЗ (упрощённое): Внедрение SEO-скилла в конвейер проекта

## Версия: 1.0
## Дата: 2026-10-21
## Приоритет: Medium
## Статус: Согласовано (упрощённая форма — малая задача, раздел 6 AGENTS.md)

## Маршрутизация
**Архитектор:** НЕ ТРЕБУЕТСЯ (документация конвейера, без БД/API/архитектуры приложения)
**Исполнитель:** Разработчик (документация + регистрация в конвейере)
**Обоснование:** Задача — систематизация SEO-знаний проекта в скилл для AI-конвейера. Изменений кода приложения нет.

---

## 1. Цель

Создать `SKILL_SEO.md` — скилл AI-SEO с кодификацией практик поисковой оптимизации,
накопленных в проекте (ЧТЗ v2–v4, Wordstat-волны, реестр посадочных, тесты-инварианты),
и зарегистрировать его в конвейере (AGENTS.md §9, SKILL_PROJECT_MAP.md §1).

## 2. Задачи

- TASK-SEO-1: Создать `SKILL_SEO.md` по формату существующих скиллов (Роль → Триггеры →
  Карта инфраструктуры → Железные правила → Алгоритмы → Тесты → Чек-лист).
- TASK-SEO-2: Зарегистрировать скилл в `AGENTS.md` (таблица §9 «Файлы скиллов»).
- TASK-SEO-3: Добавить строку в `SKILL_PROJECT_MAP.md` §1 (карта «Документация и скиллы»).

## 3. Источники знаний (кодифицировать)

- `требования/ЧТЗ_эвакуация_online_SEO_для_владельца_v2–v4.md` — методология волн, метрики, мусорные показы.
- `требования/ЧТЗ_SEO_Wordstat_2026-10.md` — Wordstat-обоснование посадочных (WS-01…05).
- `src/config/service-pages/` — реестр 16 посадочных + `index.test.ts` (инварианты).
- `src/config/geo/` — гео-посадочные Москва (округа) + МО (направления).
- `src/lib/seo/` — metadata.ts, json-ld.ts, metrika.ts (+тесты).
- `src/app/sitemap.ts`, `src/app/robots.ts` — индексация.
- Практики: дебрендинг («автоэвакуатор» — чужой бренд), чистка лемм мусорных показов,
  ночной тариф без сумм (согласовано 06.10), единый источник цен pricing.ts.

## 4. Критерии приёмки

- [ ] `SKILL_SEO.md` существует, следует формату скиллов проекта, содержит карту
      SEO-инфраструктуры, ≥10 железных правил, 4 алгоритма (новая посадочная / правка
      существующей / Wordstat-волна / чистка мусорных показов), список тестов-инвариантов.
- [ ] Все упоминаемые пути файлов существуют в проекте.
- [ ] Числа-инварианты (title ≤60, description ≤160, FAQ 3–5 и т.д.) соответствуют
      фактическим проверкам в `src/config/service-pages/index.test.ts`.
- [ ] `AGENTS.md` §9 содержит строку SEO-скилла.
- [ ] `SKILL_PROJECT_MAP.md` §1 содержит строку `SKILL_SEO.md`.
- [ ] Код приложения не изменён (только 3 md-файла), `npm run test` остаётся зелёным.
