# ЧТЗ (упрощённое) — Разговорные поисковые запросы в ПОСАДОЧНЫЕ_СТРАНИЦЫ.xlsx

**Дата:** 2026-08-31
**Маршрут:** Аналитик → Разработчик → Тестировщик (DevOps не требуется — файл планирования, не входит в сборку)
**Тип задачи:** малая (1 файл, без изменений БД/API/архитектуры)

## 1. Постановка задачи

Пользователь: поисковые запросы на посадочных страницах написаны «канцелярским» языком
(«Эвакуатор в Балашихе»), тогда как реальные пользователи ищут по-разговорному
(«Эвакуатор Балашиха»). Нужно добавить в Excel-файл новый столбец с разговорными версиями
запросов для каждой посадочной страницы.

## 2. Исходные данные

Файл: `ПОСАДОЧНЫЕ_СТРАНИЦЫ.xlsx`, лист «Посадочные страницы».
- 81 строка данных, 7 столбцов: №, URL, H1, Title (meta), Тип, Раздел, Родитель (хаб).
- Типы: услуга (7), гео (69), хаб (5).
- Лист «Сводка» — без изменений.

## 3. Правила трансформации (разговорный язык)

1. Убрать предлоги: «Эвакуатор в Балашихе» → «Эвакуатор Балашиха» (имя в именительном падеже).
2. Убрать канцелярит: «Эвакуация мотоциклов и мототехники» → «Эвакуатор для мотоцикла»;
   «Эвакуация легковых автомобилей» → «Эвакуатор для легкового автомобиля».
3. Округа-хабы: «Эвакуатор в Южном округе Москвы (ЮАО)» → «Эвакуатор ЮАО Москвы».
4. Хабы Подмосковья: «Эвакуатор на востоке Подмосковья» → «Эвакуатор восток Подмосковья».
5. Районы: «Эвакуатор в Нижегородском районе» → «Эвакуатор Нижегородский район».
6. Уже разговорные запросы не меняются: «Эвакуатор с лебёдкой», «Эвакуатор после ДТП».
7. Стиль файла сохраняется: первая буква заглавная, буква «ё» сохраняется.

## 4. Изменения

- Новый столбец H «Разговорный запрос (основной)» на листе «Посадочные страницы».
- Заполнить все 81 строку (ключ сопоставления — URL).
- Исходные столбцы A–G НЕ изменять. Лист «Сводка» НЕ трогать.

## 5. Критерии приёмки

1. Столбец H добавлен, заголовок «Разговорный запрос (основной)».
2. Все 81 строка заполнена; пустых ячеек нет.
3. Столбцы A–G идентичны исходным (проверка программным сравнением до/после).
4. Каждая фраза грамматически корректна и следует правилам трансформации.
5. Форматирование заголовка скопировано с соседних заголовков.

## 6. Риски

- Файл открыт в Excel (обнаружен lock-файл `~$ПОСАДОЧНЫЕ_СТРАНИЦЫ.xlsx`): если после записи
  пользователь сохранит открытую копию из Excel — изменения будут перезаписаны.
  Перед проверкой результата файл нужно закрыть и открыть заново.
- Перед изменением создаётся резервная копия.

## 7. Исполнитель и проверки

- Исполнитель: Разработчик (Python + openpyxl, скрипт вне репозитория).
- Правило 8 (автотесты/логирование в код приложения) неприменимо: код приложения не меняется.
  Вместо этого — программная верификация данных (Тестировщик).
