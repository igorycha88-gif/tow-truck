# ЧТЗ: SEO — разговорные запросы восточного направления

**Дата:** 2026-08-31
**Маршрутизация:** Аналитик → Разработчик → Тестировщик → DevOps (Маршрут 1)
**Модуль:** гео-посадочные (ADR-003), `src/config/geo/`

## 1. Проблема / Возможность

Пользователи ищут эвакуатор разговорными запросами без предлогов:
«эвакуатор Балашиха», «эвакуатор Реутов», «эвакуатор Новогиреево»,
«эвакуатор Горьковка», «эвакуатор шоссе Энтузиастов». Текущие меты
используют каноническую форму «Эвакуатор в Балашихе» — не совпадает
с реальным поисковым спросом. Под страницы для трасс Горьковка (М-7)
и шоссе Энтузиастов отсутствуют.

## 2. Задачи

### TASK-FRT-1. Разговорные меты существующих страниц

| Страница | Было (title / H1) | Станет |
|---|---|---|
| `/evakuator-balashiha` | Эвакуатор в Балашихе… / Эвакуатор в Балашихе | **Эвакуатор Балашиха — 24/7, подача ~20 минут** / **Эвакуатор Балашиха** |
| `/evakuator-reutov` | Эвакуатор в Реутове… / Эвакуатор в Реутове | **Эвакуатор Реутов — 24/7, подача ~15 минут** / **Эвакуатор Реутов** |
| `/evakuator-novogireevo` | Эвакуатор в Новогиреево… / Эвакуатор в Новогиреево | **Эвакуатор Новогиреево — 24/7, подача ~15 минут** / **Эвакуатор Новогиреево** |

- description каждой из трёх страниц начинается с разговорного ключа
  («Эвакуатор Балашиха: …» и т.д.).
- `nameIn` НЕ меняется — грамматика FAQ/priceNote сохраняется
  («Сколько стоит эвакуатор в Балашихе?»).
- Механизм: опциональное поле `h1Name` в `GeoLocality` (переопределяет
  имя в H1, по умолчанию — `nameIn`).

### TASK-FRT-2. Новые посадочные «Эвакуатор Горьковка» (mo-vostok)

- URL: `/evakuator-gorkovka`, slug `gorkovka`, nameIn «на Горьковке»,
  distanceKm 1 (шоссе начинается у МКАД).
- title: «Эвакуатор Горьковка — 24/7, подача ~20 минут», H1 «Эвакуатор Горьковка».
- Контент: М-7 от МКАД до Ногинска, развязки, погрузка с обочины,
  доставка в Москву. 3 localIncluded + 2 localFaq, уникальные.
- related: `evakuator-balashiha`, `evakuator-shosse-entuziastov`.

### TASK-FRT-3. Новая посадочная «Эвакуатор шоссе Энтузиастов» (moscow-vao)

- URL: `/evakuator-shosse-entuziastov`, slug `shosse-entuziastov`,
  nameIn «на шоссе Энтузиастов» (шоссе целиком в Москве, ВАО).
- title: «Эвакуатор шоссе Энтузиастов — 24/7, ~20 минут», H1 «Эвакуатор шоссе Энтузиастов».
- areaServed (schema.org): «шоссе Энтузиастов, Москва» — опциональное поле
  `areaNameOverride` в `GeoLocality` (композер иначе сгенерирует «район …»).
- Контент: трасса от центра до МКАД, пробки, погрузка на обочине,
  связь с М-7 и Балашихой. 3 localIncluded + 2 localFaq, уникальные.
- related: `evakuator-novogireevo`, `evakuator-gorkovka`.

## 3. Ограничения (анти-дорвей, ЧТЗ_Гео §3.2)

- Уникальность по всем 83 страницам: title, description, H1, lead[0], lead[1],
  вопросы FAQ, заголовки localIncluded.
- title ≤60 симв., ключ «эвакуатор» в первых 30; description ≤160; лиды >80 симв.;
  ответы FAQ >60 симв.; объём страницы ≥350 слов.
- Цены только из `pricing.ts` (kind: fromMin, без хардкода сумм в текстах).
- Все related-слаги существуют; related локации 2–3, начинается с хаба.

## 4. Не входит в объём

- Переименование остальных 65+ локаций на разговорный шаблон (отдельная задача
  при подтверждении эффекта).
- Правка хабов, кроме автоматически собираемой перелинковки.

## 5. Критерии приёмки

1. `/evakuator-balashiha`: title и H1 начинаются с «Эвакуатор Балашиха»;
   аналогично Реутов и Новогиреево; FAQ/цены грамматически корректны
   (nameIn сохранён).
2. `/evakuator-gorkovka` и `/evakuator-shosse-entuziastov` открываются (SSG 200),
   H1 соответствуют запросам, в sitemap.xml, в перелинковке хабов и соседних
   локаций.
3. `npm run test && npm run lint && npx tsc --noEmit` — зелёные,
   счётчики тестов актуальны (76/70/83, ВАО 15, МО-восток 11).
4. JSON-LD areaServed новой страницы ВАО — «шоссе Энтузиастов, Москва».

## 6. Риски

- Просадка позиций по старым формам «эвакуатор в Балашихе» минимальна:
  формы отличаются только предлогом, страница та же (URL не меняется),
  301 не нужны.
- Хронология переиндексации — Яндекс/Google обновят меты в 1–2 недели.
