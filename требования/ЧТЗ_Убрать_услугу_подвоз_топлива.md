# ЧТЗ: Убрать услугу «Подвоз топлива и запуск» с сайта

## Контекст
На сайте в каталоге услуг присутствует услуга «Подвоз топлива и запуск»
(slug: `fuel`). Пользователь просит убрать эту услугу с сайта. Упоминается
в каталоге услуг, типах, валидаторе заявок, SEO-описании и преимуществах.

## Решение (маршрутизация)
Полностью удалить услугу `fuel` из системы: каталога услуг, типа `ServiceType`,
массива `SERVICE_TYPES`, zod-валидатора заявок. Обновить тексты (SEO-описание и
текст преимущества), где услуга упоминается, чтобы не осталось «висящих» ссылок
на несуществующую услугу.

**Маршрут:** Аналитик → Разработчик → Тестировщик → DevOps (Маршрут 1, код-задача).
**Архитектор:** не требуется (нет изменений БД/API/архитектуры).

## Критерии приёмки
1. Услуга «Подвоз топлива и запуск» **не выводится** в каталоге услуг на сайте.
2. Тип `ServiceType` и массив `SERVICE_TYPES` **не содержат** `'fuel'`.
3. Zod-схема заявки (`orderSchema.serviceType`) **не принимает** `'fuel'`.
4. В SEO-описании (`siteConfig.description`) и тексте преимущества нет упоминания
   «подвоз топлива» / «запуск».
5. Автотесты обновлены: нет ссылок на `'fuel'` как валидный тип услуги.
6. `npm run test && npm run lint && npx tsc --noEmit` — зелёные.

## Список файлов
- `src/config/services.ts` — удалить объект услуги `fuel`
- `src/types/index.ts` — убрать `'fuel'` из `ServiceType` и `SERVICE_TYPES`
- `src/lib/validators/order.ts` — убрать `'fuel'` из zod enum
- `src/config/advantages.ts` — обновить текст преимущества (убрать «подвоз топлива, запуск»)
- `src/config/site.ts` — обновить SEO-описание
- `src/services/notifyService.test.ts` — заменить `'fuel'` на валидный тип в тесте
