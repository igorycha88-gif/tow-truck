## 1. Цели и задачи

### 1.1 Бизнес-цель
Прописать реальные контактные данные компании на сайте:
- **Телефон:** `+79017054540` (отображение `+7 (901) 705-45-40`, ссылка `tel:+79017054540`)
- **Email:** `boronind1m@yandex.ru` (ссылка `mailto:boronind1m@yandex.ru`)

### 1.2 Пользовательская ценность
Везде, где сейчас показан телефон, рядом доступна и почта (как `mailto`-ссылка),
а также телефон кликабелен с реальным номером. Это повышает конверсию и доверие.

## 2. Функциональные требования

### 2.1 User Stories + Acceptance Criteria

**US-1. Реальный телефон на всём сайте**
- *Given* любая страница сайта
- *When* отображается телефон
- *Then* номер = `+7 (901) 705-45-40`, `tel:`-ссылка = `tel:+79017054540`

**US-2. Email отображается рядом с телефоном**
- *Given* Header / Footer / Contacts / Hero / OrderSection
- *When* отрисован блок контактов
- *Then* рядом с телефоном видна почта `boronind1m@yandex.ru` как `mailto:`-ссылка

**US-3. Email в SEO-данных**
- *Given* метадата главной (buildMetadata) и JSON-LD (localBusinessLd)
- *When* формируется метадата
- *Then* присутствуют `og:email` и `email` в LocalBusiness schema

**US-4. Email доступен на клиенте**
- *Given* рендер в браузере
- *When* читается `company.email`
- *Then* значение определено (используется `NEXT_PUBLIC_EMAIL` с дефолтом)

### 2.2 Границы (вне объёма)
- FloatingCallBtn — остаётся только круглая кнопка звонка (email туда не добавляется,
  это icon-only CTA на мобильных).
- `NOTIFY_EMAIL` (получатель уведомлений на сервере) — не меняется логически,
  обновляется только значение в `.env.example` для консистентности.

## 3. Технические решения

### 3.1 Источник данных (централизованно через `src/config/company.ts`)
```ts
const phoneDigits = process.env.NEXT_PUBLIC_PHONE || '+7 (901) 705-45-40';
const phoneHref = `tel:${phoneDigits.replace(/[^+\d]/g, '')}`;
const email = process.env.NEXT_PUBLIC_EMAIL || 'boronind1m@yandex.ru';
// company.email = email; company.emailHref = `mailto:${email}`;
```
**Почему `NEXT_PUBLIC_EMAIL`** (новая переменная): текущий `company.email` берётся из
`NOTIFY_EMAIL` — это серверная переменная, недоступная в браузере. Для публичного
отображения нужен `NEXT_PUBLIC_*` префикс (Next.js инлайнит в клиентский бандл).

### 3.2 Изменение типов (`src/types/index.ts`)
Добавить `emailHref?: string;` в `CompanyInfo` (симметрично `phoneHref`).
