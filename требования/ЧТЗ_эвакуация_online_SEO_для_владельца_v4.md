#### TASK-EV-1: Разобрать мусорные показы — посадочные и чистка текстов (1 час)

**Почему:** 5 из 11 кликов недели — мусор: «ави», «договор банковского обслуживания образец», «заказать seo продвижение сайта в яндекс», «ростелеком спб адреса невский район», «сервис донатов». Регион в Вебмастере стоит (Москва + МО — подтверждено владельцем 06.10), значит Яндекс матчит эти запросы с текстами наших 120 страниц по случайным словам («договор», «образец», «сервис», «заказать» и т.п.) — по таким запросам нет конкуренции вообще. Мусорные переходы портят поведенческие сигналы посадочных страниц.

**Что сделать:**
1. Вебмастер → «Поисковые запросы» → по каждому мусорному запросу открыть «посадочные страницы» — зафиксировать, КАКАЯ страница ранжируется.
2. На найденных страницах найти случайные вхождения слов: «договор», «образец», «банк», «сервис», «продвижение», «адреса» — переформулировать (например, «договор» → «официальное оформление заявки», убрать шаблонные юридические тексты с service-страниц).
3. Проверить служебные/шаблонные страницы (оферта, реквизиты): если ранжируются они — вынести шаблонный текст в картинки или закрыть от индексации (noindex на служебные).
4. Через неделю — контроль: доля мусорных кликов в данных мониторинга.

**Критерии приёмки:**
- [ ] Список мусорных запросов → посадочные зафиксирован
- [ ] Тексты почищены, служебные страницы закрыты при необходимости
- [ ] К 20.10: мусорные клики <15% (проверит мониторинг)
