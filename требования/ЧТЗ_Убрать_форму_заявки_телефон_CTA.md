# ЧТЗ: Убрать форму заявки со сайта, перевести CTA на звонок

**Дата:** 15.09.2026
**Маршрут:** Аналитик → Разработчик → Тестировщик → DevOps (Маршрут 1)
**Исполнитель после ЧТЗ:** Разработчик
**Архитектор:** НЕ требуется (нет изменений БД/API/архитектуры)

---

## 1. Бизнес-задача

Владелец решил отказаться от приёма заявок через форму на сайте. Все точки
конверсии перевести на прямой звонок: кнопка «Заказать эвакуатор» должна быть
ссылкой на номер телефона (`tel:`). В мобильной версии нажатие = вызов звонилки
на номер сайта.

## 2. Что меняется (постановка)

1. **Убрать форму заявки** (`OrderForm`) со ВСЕХ страниц сайта:
   - Главная: секция `#order` (`OrderSection`).
   - Посадочные страницы услуг и гео: секция `#order-service` (`ServicePage`).
2. **Кнопка «Заказать эвакуатор»** в Hero главной — сделать `tel:`-ссылкой
   на номер `company.phone` (`+7 (901) 705-45-40` → `tel:+79017054540`).
3. **Секция `#order` на главной** — сохранить (на неё ссылается навигация
   `/#order`, e2e-тесты, json-ld), но вместо формы — телефонный CTA: заголовок,
   крупная кнопка-телефон (`tel:`), преимущества.
4. **Секция `#order-service` на страницах услуг** — сохранить id, вместо
   колонки с формой — телефонный CTA с крупной `tel:`-кнопкой.
5. **Кнопка «Оставить заявку»** в hero страницы услуг (`#order-service` якорь) —
   заменить на `tel:`-кнопку с номером телефона.

## 3. Ограничения и неизменяемое

- **НЕ трогать:** API `/api/orders`, валидатор `order.ts`, БД (Prisma),
  Telegram-уведомления — backend остаётся работать (формы на сайте просто нет).
- **НЕ менять** номер телефона: источник `src/config/company.ts` (ENV `NEXT_PUBLIC_PHONE`).
- Клик-трекер `ClickEventsTracker` ловит все `a[href^="tel:"]` автоматически —
  новые кнопки попадают в метрики `click_phone` без доработок. Для корректного
  `page` в метриках сохранять атрибут `data-page` как у соседних tel:-ссылок.
- Иконки/стили — по действующей дизайн-системе (buttonVariants, lucide-react `Phone`).
- 152-ФЗ: чекбокс согласия исчезает вместе с формой (нет сбора ПД через сайт).

## 5. Критерии приёмки

1. На главной и всех посадочных страницах ОТСУТСТВУЕТ форма заявки (нет `#order form`, `#order-service form`, нет чекбокса согласия).
2. Кнопка «Заказать эвакуатор» в Hero главной — `<a href="tel:+79017054540">`.
3. Секция `#order` существует и содержит видимую `tel:`-кнопку с номером.
4. Секция `#order-service` существует на страницах услуг и содержит `tel:`-кнопку.
5. Навигация «Заказать» (`/#order`) работает (секция с id сохранена).
6. `npm run test && npm run lint && npx tsc --noEmit` — без ошибок.
7. E2E обновлены и проходят: tel:-ссылки на месте, формы нет.

  Telegram не видны посетителю, удаление — отдельная задача владельца.
- **Что с кнопкой «Оставить заявку» на страницах услуг?** Заменяется на tel:.
