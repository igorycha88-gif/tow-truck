# ЧТЗ: 152-ФЗ — маскирование IP при записи и актуализация политики конфиденциальности

## Версия: 1.0
## Дата: 2026-10-14
## Автор: AI-Аналитик
## Приоритет: High (соответствие)
## Статус: Active

## 1. Контекст

Сайт собирает IP-адрес посетителей (таблицы Visit, ClickEvent, Order). По
доминирующей практике IP сам по себе не ПДн (ВАС РФ № 610/14), однако
консервативная трактовка РКН требует минимизации. Политика конфиденциальности —
заглушка: не упоминает аналитику, IP, гео, Метрику, cookie (пробел).

## 2. Решение (согласовано с владельцем 2026-10-14)

1. **Маскировать IP перед записью в БД** во всех точках записи:
   - IPv4: последний октет → 0 (`77.88.8.8` → `77.88.8.0`);
   - IPv6: обрезать до /64 (первые 4 группы + `::`);
   - `::ffff:`-mapped сначала нормализуется (normalizeIp), затем маскируется как IPv4.
2. **Полный IP остаётся только в рамках запроса**: rate-limit и гео-lookup
   (GeoLite2 точнее по полному IP) — в БД не попадает.
3. Метрики не деградируют: уникальные посетители v2 — по visitorId, сессии — по
   sessionId; IP — только fallback; гео по /24-префиксу определяется корректно.
4. **Политика конфиденциальности**: раздел «Какие данные мы обрабатываем»
   расширяется блоком про обезличенную статистику (маскированный IP, город,
   устройство, страницы/переходы/время, UTM, случайные идентификаторы
   cookie/localStorage/sessionStorage, Яндекс.Метрика), цели, сроки, способ
   отказа. Плашка «заготовочный текст» удаляется.
5. Легаси-записи с полными IP не мигрируются (исторических строк мало; чистка
   старых данных — отдельная задача).

## 3. Файлы

- `src/lib/utils.ts` — `maskIp()` + unit-тесты (`utils.test.ts`)
- `src/app/api/visit/route.ts`, `src/app/api/click-event/route.ts`,
  `src/app/api/orders/route.ts` — `maskIp(ip)` при передаче в сервис
  (rate-limit/гео — по полному IP)
- `src/app/politika/page.tsx` — актуализация текста
- Обновление route-тестов (в БД маскированный IP, lookupCity — полный)

## 4. Критерии приёмки

1. В Visit/ClickEvent/Order записывается только маскированный IP.
2. Rate-limit срабатывает по полному IP (одна подсеть ≠ один лимит).
3. Гео-город определяется по полному IP (точность не падает).
4. Метрики visitors/sessions/geo на маскированных данных работают.
5. Политика описывает обезличенную статистику и Метрику; плашка убрана.
6. `npm run test && npm run lint && npx tsc --noEmit` — зелёные.
