1. **Сайт уже показывается в топ-10 по районам и спецтранспорту — но кликов ноль.** Причины: нет посадочных страниц под конкретный интент + слабые сниппеты. Каждая страница ниже = прямое превращение показов в звонки.

## 3. Нефункциональные требования (обязательны для всех страниц)

1. **Анти-дорвей:** ≥30% уникального локального текста на каждой районной странице (улицы, реалии проездов, время подачи). Без этого Яндекс пессимизирует весь домен.
2. **Не делать матрицу «район×услуга»** — одна богатая страница на район.
3. **Только оригинальный контент** — копипаст = фильтр Яндекса.
4. **Мобильная версия: телефон-кнопка и форма выше_fold** — трафик «стою на дороге» почти 100% мобильный.
5. **Скорость:** каждая страница < 3 сек LCP (мобильная).
6. **Переобход** каждой новой страницы в Яндекс.Вебмастере в день публикации.
7. **Микроразметка:** `LocalBusiness` + `areaServed` + `FAQPage` — на всех районных страницах.

## 4. Риски

| Риск | Митигация |
|---|---|
| Тощие районные страницы → пессимизация | требование ≥30% локальной уникальности (п. 3.1) |
| Услуги (спецтехника, аренда, техпомощь) не оказываются на деле | владелец подтверждает список услуг ДО публикации страницы |
| Районы вне фактической зоны быстрой подачи | указывать честное время подачи по районам |
| Подрядчик «сделает быстро шаблоном» | приёмка по критериям (в индексе + запросы/клики в Вебмастере) |
