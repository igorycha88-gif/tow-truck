# ЧТЗ — Обновление структуры цен на услуги эвакуации

**Дата:** 2026-07-26
**Маршрут:** Стандартный (Аналитик → Разработчик → Тестировщик → DevOps)
**Исполнитель:** Разработчик → Тестировщик → DevOps
**Тип:** Контент + модель данных (config-driven, без БД)

---

## 1. Контекст и проблема

Текущие цены на сайте — заглушки (`priceFrom: number`, показ «от X ₽`). Не отражают
реальную тарификацию. Заказчик утвердил новую модель: **подача (базовый выезд) +
стоимость за километр**, а для двух услуг — **«Цена по запросу»**.

## 2. Утверждённые цены (источник: заказчик, 2026-07-26)

| slug | Услуга | Модель | Подача (₽) | ₽/км |
|------|--------|--------|-----------|------|
| `light_vehicle` | Эвакуация легковых авто | тариф | 5000 | 100 |
| `moto` | Эвакуация мотоциклов | тариф | 5000 | 100 |
| `offroad` | Внедорожники и кроссоверы | тариф | 6000 | 100 |
| `accident` | После ДТП | по запросу | — | — |
| `commercial` | Эвакуация спецтехники | по запросу | — | — |

## 3. Критерии приёмки

1. На сайте (секция «Услуги») для тарифных услуг отображается:
   `Подача 5 000 ₽ • 100 ₽/км` (формат цены — `formatPrice`, неразрывный пробел).
2. Для услуг «по запросу» (accident, commercial) отображается: `Цена по запросу`.
3. Модель данных типобезопасна: невозможно задать тариф без `baseFee`/`perKm` или
   смешать «по запросу» с числами (использовать discriminated union).
4. SEO `priceRange` (LocalBusiness JSON-LD, `src/lib/seo/metadata.ts`) обновлён с
   `от 2000 ₽` до `от 5000 ₽` (минимальная подача).
5. Все существующие автотесты обновлены и проходят; добавлены тесты на новую модель цен
   и helper форматирования (happy + edge cases). Покрытие новых файлов ≥ 60%.
6. `npm run test && npm run lint && npx tsc --noEmit` — зелёные.
7. Регрессия: карточки кликабельны, предзаполнение `?service=slug#order` работает,
   иконки рендерятся, layout не сломан.

## 4. Декомпозиция (TASK)

- **TASK-PRC-BCK-1 (модель/types):** В `src/types/index.ts` заменить `priceFrom: number`
  на `pricing: ServicePricing`, где
  ```ts
  type ServicePricing =
    | { kind: 'tariff'; baseFee: number; perKm: number }
    | { kind: 'onRequest' };
  ```
- **TASK-PRC-BCK-2 (config):** Обновить `src/config/services.ts` ценами из таблицы §2;
  убрать комментарий про заглушки; оставить описание/иконки без изменений.
- **TASK-PRC-BCK-3 (helper):** Добавить чистую функцию `formatPricing(pricing): string`
  в `src/lib/utils.ts` (или `src/config/services.ts`): тариф →
  `Подача {formatPrice(baseFee)} • {perKm} ₽/км`; onRequest → `Цена по запросу`.
- **TASK-PRC-FRT-1 (UI):** `src/components/sections/Services.tsx` — заменить строку
  `от {formatPrice(service.priceFrom)}` на `{formatPricing(service.pricing)}`.
- **TASK-PRC-INF-1 (SEO):** `src/lib/seo/metadata.ts` — `priceRange: 'от 5000 ₽'`.
- **TASK-PRC-TST-1 (тесты):** Обновить `src/config/config.test.ts`:
  - tariff-услуги: `baseFee > 0 && perKm > 0`;
  - onRequest-услуги: `pricing.kind === 'onRequest'`.
  Добавить unit-тесты на `formatPricing` (tariff / onRequest / минимальные значения).

## 5. Замечание о логировании (Правило 8)

Изменение затрагивает только **синхронный конфиг и Server Component без ввода-вывода**
(нет API routes, нет БД, нет async-операций). Структурное логирование pino здесь
применять не к чему. Правило 8 выполняется через автотесты (`formatPricing`, консистентность
каталога). Если в ходе реализации появится любой async/service — добавить логирование.
