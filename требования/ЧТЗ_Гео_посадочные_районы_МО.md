# ЧТЗ: Гео-посадочные SEO-страницы — районы Москвы (ВАО/ЮАО/ЮВАО) и города МО ≤30 км

## Версия: 1.0
## Дата: 2026-08-25
## Автор: AI-аналитик (конвейер), согласовано с заказчиком (максимальный охват)
## Приоритет: High
## Статус: Согласовано

---

## 1. Цели и задачи

### 1.1 Бизнес-цель
Рост видимости в Яндексе по гео-запросам («эвакуатор марьино», «эвакуатор люберцы»,
«эвакуатор ювао») за счёт посадочных страниц под каждый район Москвы (восток, юг,
юго-восток — 41 район) и города ближнего Подмосковья ≤30 км от МКАД по тем же
направлениям (27 городов), с хабами направлений.

### 1.2 Пользовательская ценность
Клиент ищет «эвакуатор <мой район>» → попадает на страницу с локальной
конкретикой (шоссе, улицы, метро, время подачи) и формой заказа с предзаполненной
услугой.

### 1.3 Метрики успеха
- ~74 новые индексируемые гео-страницы в sitemap (68 локаций + 6 хабов)
- Уникальные title/description/H1/лиды/FAQ — без дублей (автотесты)
- Индексация Я.Вебмастером (вне рамок ЧТЗ, мониторинг после релиза)

## 2. Функциональные требования

### 2.1 User Stories (Given-When-Then)

**US-1.** Как пользователь из Марьино, я ищу «эвакуатор марьино» в Яндексе.
- GIVEN открыта `/evakuator-marino`
- WHEN страница загружена
- THEN H1 «Эвакуатор в Марьино», лид упоминает Люблинскую улицу/метро Марьино,
  цена из единого источника, форма заказа с предзаполненной услугой, FAQ, JSON-LD
  Service + FAQPage + BreadcrumbList (Главная → Хаб ЮВАО → Марьино).

**US-2.** Как пользователь с трассы М-5, я попадаю на хаб юго-востока МО.
- GIVEN открыта `/evakuator-yugo-vostok-podmoskovya`
- THEN блок перелинковки «Города направления» содержит Люберцы, Жуковский,
  Раменское и др. (все локации направления).

**US-3.** Незнакомый слаг.
- GIVEN GET `/evakuator-ne-izvestnyj`
- THEN 404 (dynamicParams = false).

### 2.2 Состав страниц

**Хабы (6):** `evakuator-vao-moskvy`, `evakuator-yuao-moskvy`,
`evakuator-yuvao-moskvy`, `evakuator-vostok-podmoskovya`,
`evakuator-yugo-vostok-podmoskovya`, `evakuator-yug-podmoskovya`.

**ВАО (14):** bogorodskoe, veshnyaki, vostochnyj, golyanovo, ivanovskoe,
izmajlovo, kosino-uhtomskij, metrogorodok, novogireevo, perovo,
preobrazhenskoe, severnoe-izmajlovo, sokolinaya-gora, sokolniki.

**ЮВАО (12):** vyhino-zhulebino, kapotnya, kuzminki, lefortovo, lyublino,
marino, nekrasovka, nizhegorodskij, pechatniki, ryazanskij, tekstilshiki,
yuzhnoportovyj.

**ЮАО (15):** biryulevo-vostochnoe, biryulevo-zapadnoe, brateevo, danilovskij,
donskoj, zyablikovo, moskvoreche-saburovo, nagatinskij-zaton,
nagatino-sadovniki, orehovo-borisovo-severnoe, orehovo-borisovo-yuzhnoe,
caricyno, chertanovo-severnoe, chertanovo-centralnoe, chertanovo-yuzhnoe.

**МО восток (10, ≤30 км):** reutov (~2), balashiha (~4), zheleznodorozhnyj (~8),
chernoe (~15), staraya-kupavna (~16), monino (~20), elektrougli (~21),
shelkovo (~23), fryazino (~24), losino-petrovskij (~29).

**МО юго-восток (14, ≤30 км):** kotelniki (~2), lyubercy (~3), dzerzhinskij (~3),
tomilino (~7), malahovka (~9), udelnaya (~10), kraskovo (~11), lytkarino (~12),
oktyabrskij (~12), bykovo (~15), ilinskij (~15), zhukovskij (~16),
ramenskoe (~25), bronnicy (~27).

**МО юг (3):** shcherbinka (~4), podolsk (~15), domodedovo (~16).
Существующая `evakuator-vidnoe` привязывается к хабу юга (breadcrumbs).

Все слаги с префиксом `evakuator-`. Транслитерация проекта: ё→e, й→j, х→h,
ц→c, ч→ch, ш→sh, щ→sch, ж→zh, я→ya, ю→yu, ы→y.

### 2.3 Структура каждой гео-страницы (переиспользует ServicePage)
H1 → бейджи (подача/24-7/цена) → лид (2 абзаца) → «Что входит» (6 карточек:
3+ локальных, остальные направления) → цена (единый источник, kind=fromMin) →
шаги (4) → FAQ (4: 2 локальных + 2 направления с именем локации) → CTA + форма
(light_vehicle) → перелинковка (хаб + 2 смежные).

## 3. Нефункциональные требования

### 3.1 Производительность
SSG (generateStaticParams из объединённого реестра), Server Components, без
нового клиентского JS. LCP не деградирует (статика, кэш).

### 3.2 Анти-дорвей (критично для Яндекса)
- Уникальные (по всем ~81 посадочным): title, description, H1, оба лид-абзаца,
  вопросы FAQ, заголовки карточек included — контролируется автотестами (Set).
- ≥350 слов текста на страницу.
- Локальные факты в каждой странице: шоссе/улицы/метро/ориентиры.
- title ≤60 симв., ключ «эвакуатор …» в первых 30; description ≤160.

### 3.3 SEO
- canonical + OG — через buildMetadata (exactTitle)
- JSON-LD: Service (areaServed + areaName локации), FAQPage, BreadcrumbList
  (Главная → Хаб → Локация)
- sitemap: локации priority 0.7, хабы 0.8, changeFrequency monthly
- Перелинковка: локация → хаб + 2; хаб → все локации направления; Видное →
  хаб юга; нет страниц-сирот

### 3.4 Логирование
Статические конфиги/SSG — нового API нет; логирование N/A (существующие
logger в api/orders, VisitTracker остаются без изменений).

## 7. Тестирование

### 7.1 Vitest
- Реестр: количество (41+27+6), слаги валидны `^[a-z0-9-]+$`, уникальны
- Уникальность по всем 81: title/desc/h1/лиды/вопросы FAQ/included titles
- Структура: title ≤60 (ключ в первых 30), desc ≤160, lead ≥2×80 симв.,
  included ≥5, faq 3–5 (ответы >60), слова ≥350, related: локации 2–3 и
  существуют, хаб ссылается на все локации направления, локации — на хаб
- МО: distanceKm ≤ 30; direction из допустимых
- Цена: только подстроки из pricing.ts (как в service-pages тестах)
- sitemap: содержит все гео-слаги, URL уникальны, приоритеты 0.7/0.8

### 7.2 E2E (Playwright)
- smoke: 3 гео-страницы (район ЮВАО, город МО, хаб) отвечают 200, содержат H1
  и форму; несуществующий слаг — 404

## 8. Риски и зависимости
- Фильтр «качество» Яндекса → уникальность + локальные факты + перелинковка
- Каннибализация хаб/район → разные интенты и меты
- Объём контента → данные компактны, общие блоки в композере
