| Метрика | Значение | Оценка |
|---------|----------|--------|
| Показов/нед | 148 | очень мало |
| Кликов/нед | **0** | критично |
| CTR сниппетов | **0%** | критично (норма на поз. 5–10: 2–5%) |
| Средняя позиция | 11.0 | ниже топ-5 |
| Показы в топ-10 | 105 (71%) | формально ок |
| Показы в топ-5 | 8 (5%) | критично мало |

**Выводы:**

1. **CTR = 0%** — органика задавлена рекламой и однастрочниками Яндекс.Карт;
   сниппеты не дают повода кликнуть.
2. **Семантика полу-брендовая:** ~60% показов (89 из 148) — кластер «эвакуатор 24 7»
   (название сайта). Реальные коммерческие запросы почти не приводят.
3. **Word-salad запросы в индексе** («подаем ракету в любой посёлок», «просевшая
   страна… труп…») — на страницах остались сгенерированные текстовые блоки,
   риск антиспам-фильтра Яндекса.
4. **Гео-покрытие неполное:** закрыты восток/юг/юго-восток Москвы и МО.
   Запад (ЗАО) и юго-запад (ЮЗАО) Москвы — не закрыты, посадочных нет.
5. **Парк ограничен 15 тоннами** — сайт при этом обещает «грузовики, автобусы»
   (faq.ts, services.ts). Это несоответствие факту портит конверсию
   (заявки, которые не сможем выполнить) и размывает релевантность.

#### 3.1. Литературные + разговорные запросы (КЛЮЧЕВОЕ ТРЕБОВАНИЕ)

В описаниях каждой новой страницы должны присутствовать **обе формы** запросов:

| Форма | Примеры (ЮЗАО/ЗАО) |
|-------|--------------------|
| **Разговорные** (как ищут люди) | «эвакуатор ясенево», «эвакуатор кунцево», «эвакуатор юзао», «эвакуатор зао», «вызвать эвакуатор раменки», «эвакуатор рядом со мной», «эвакуатор дешево москва», «эвакуатор сколько стоит» |
| **Литературные** (канонические) | «эвакуатор в ясенево», «эвакуация автомобиля в районе кунцево», «услуги эвакуатора в западном округе москвы», «круглосуточная эвакуация авто в юзао», «заказать эвакуатор в раменках» |

**Распределение по элементам страницы:**

| Элемент | Форма | Требование |
|---------|-------|------------|
| title (≤60 симв.) | разговорная | «Эвакуатор Ясенево — 24/7, подача ~20 минут»; ключ «эвакуатор …» в первых 30 симв. |
| H1 | разговорная | «Эвакуатор Ясенево» — через `h1Name` (механизм ЧТЗ_Разговорные_Восток) |
| description (≤160) | обе | начинается разговорной формой, литературная внутри: «Эвакуатор Ясенево: круглосуточно, подача ~20 минут. Эвакуатор в Ясенево и по всему ЮЗАО — от 5 000 ₽.» |
| lead[0] | разговорная | разговорный ключ + УТП |
| lead[1] | литературная | «Вызовите эвакуатор в Ясенево…» + локальные факты (шоссе/улицы/метро) |
| nameIn | литературная | «в Ясенево», «в Крылатском», «в Раменках» — корректная предложная форма для FAQ/priceNote, НЕ меняется |
| localFaq[2] | смешанно | 1 вопрос литературно («Сколько стоит эвакуатор в Ясенево?»), 1 разговорно («Эвакуатор Ясенево — как быстро приедете?») |
| Хаб-меты | обе | title «Эвакуатор ЮЗАО Москва — 24/7, подача ~20 минут»; description содержит «эвакуатор в юго-западном округе Москвы» |

Цена — только из `pricing.ts` (`priceFromLabel()` / `perKmLabel()`), без хардкода.

#### 3.2. Структура страницы и данные

Переиспользует ServicePage (ЧТЗ_Гео §2.3): H1 → бейджи → лид (2 абзаца) →
«Что входит» (6 карточек: 3+ локальных) → цена (kind=fromMin) → шаги →
FAQ (2 локальных + 2 направления) → CTA + форма (light_vehicle) →
перелинковка (хаб + 2 смежные).

`GeoLocality`: slug, name, nameIn, h1Name, direction (новые константы
`yuzao`/`zao` в допустимых), kind: district, metro?[], highways[], streets?[],
landmarks?[], уникальные title/description/lead[2]/localIncluded[3]/localFaq[2].

## 7. Тестирование (vitest)

1. **Реестр:** количества (94/8/102/109), слаги `^[a-z0-9-]+$`, уникальны;
   directions `yuzao`/`zao` валидны.
2. **Уникальность 109 страниц:** title/description/H1/лиды/FAQ/included.
3. **Обе формы запросов (новое):** для каждой локации ЮЗАО/ЗАО — title/H1
   начинаются с разговорного ключа «Эвакуатор <Имя>»; description содержит
   литературную форму («в <nameIn>» / «округе»); nameIn непустой.
4. **Грамматика nameIn:** предложная форма корректна (в Крылатском, в Раменках,
   в Тёплом Стане, в Кунцево, в Ясенево…).
5. **Forbidden-словарь (грузовое):** `/грузовик|автопоезд|полуприцеп|фура/`
   по `src/` → пусто; вхождение «тонн» допустимо только как «до 15 тонн».
6. **Анти-дорвей:** длины (title ≤60, desc ≤160, лиды >80, FAQ ответы >60,
   слова ≥350), локальные факты (metro/highways непустые), related 2–3
   существуют и начинаются с хаба, цены — подстроки pricing.ts.
7. **sitemap:** все 102 гео-URL, уникальны, приоритеты 0.7/0.8.
8. **E2E (Playwright, data-driven smoke):** по 1 странице ЮЗАО и ЗАО + оба
   хаба — 200, H1 и форма на месте; несуществующий слаг — 404.
