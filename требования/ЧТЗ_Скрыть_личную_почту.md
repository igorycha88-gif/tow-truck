# ЧТЗ: Скрыть личную почту с сайта

## Контекст
На сайте публично отображается личная почта `boronind1m@yandex.ru` (захардкожена
как фолбэк в `src/config/company.ts`). Пользователь просит убрать её с сайта, т.к.
она личная.

## Решение (маршрутизация)
Сделать поле `company.email` **необязательным**: убрать захардкоженный личный email
как фолбэк. По умолчанию `company.email = undefined`. Все блоки с почтой рендерятся
только если email задан через `NEXT_PUBLIC_EMAIL` (публичный email можно добавить
позже без правки кода).

**Маршрут:** Аналитик → Разработчик → Тестировщик → DevOps (Маршрут 1, код-задача).
**Архитектор:** не требуется (нет изменений БД/API/архитектуры).

## Критерии приёмки
1. Личная почта `boronind1m@yandex.ru` **не выводится** нигде на сайте по умолчанию
   (Header, Footer, Hero, Contacts, OrderSection).
2. В HTML/SEO нет `og:email` и JSON-LD `email` с личной почтой (поле опускается,
   если email не задан).
3. Все UI-блоки с почтой рендерятся условно (`company.email` задан).
4. Публичный email можно включить через `NEXT_PUBLIC_EMAIL` без правки кода.
5. `npm run test && npm run lint && npx tsc --noEmit` — зелёные.
6. Логирование/тесты обновлены под новое поведение.
